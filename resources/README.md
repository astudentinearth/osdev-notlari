# Kaynaklar

OSDev alanında güvenilir birincil kaynakların derlendiği bölüm. Notlarda kullanılan referanslar mümkün olduğunca buradaki kaynaklara dayandırılır.

Bir kaynak eklerken yalnızca bağlantıyı vermek yeterli değildir: kaynağın ne olduğu, hangi konuları kapsadığı ve hangi seviyeye hitap ettiği kısaca belirtilmelidir.

## İçerik

| Konu | Dosya | Durum |
| --- | --- | --- |
| Kitaplar | `kitaplar.md` | ⬜ |
| Mimari manual'ları (Intel, AMD, ARM, RISC-V) | `manualler.md` | 🟡 |
| Spesifikasyonlar (UEFI, ACPI, PCI, USB, RFC'ler) | `spesifikasyonlar.md` | ⬜ |
| Makaleler ve akademik yayınlar | `makaleler.md` | ⬜ |
| İncelenebilecek açık kaynak projeler | `projeler.md` | ⬜ |
| Araçlar (emülatör, debugger, toolchain) | `araclar.md` | ⬜ |
| Topluluklar ve forumlar | `topluluklar.md` | ⬜ |
| Dersler ve video serileri | `dersler.md` | ⬜ |

---

**Durum işaretleri:** ⬜ yazılmadı · 🟡 yazılıyor · ✅ yayında

Kaynak eklemek için [CONTRIBUTING.md](../CONTRIBUTING.md) dosyasındaki kurallara bakın.
